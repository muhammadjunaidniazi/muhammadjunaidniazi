# 01 — Python for Machine Learning

Machine learning projects usually start with clean Python basics. Focus on the skills below before jumping into models.

## Core Concepts

- Variables store values.
- Lists store multiple values.
- Dictionaries store key-value data.
- Functions help reuse logic.
- Loops repeat tasks.
- Conditions control decisions.

## Practice Task

Create a Python function that receives a student's study hours and returns a simple message:

```python
def study_feedback(hours):
    if hours >= 5:
        return "Strong preparation"
    if hours >= 3:
        return "Good, but improve practice"
    return "Needs more study time"
```

## Why It Matters

ML code uses Python functions, loops, and conditions for preprocessing, model testing, and result analysis.
