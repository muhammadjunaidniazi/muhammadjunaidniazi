# 03 — Model Evaluation

Model evaluation tells whether a trained model is useful or not.

## Regression Metrics

- **MAE:** Average absolute prediction error.
- **MSE:** Squared prediction error.
- **R2 Score:** Shows how much variance the model explains.

## Classification Metrics

- **Accuracy:** Correct predictions divided by all predictions.
- **Precision:** How many predicted positives were actually positive.
- **Recall:** How many real positives were found.
- **F1-score:** Balance between precision and recall.
- **Confusion Matrix:** Table of correct and wrong predictions.

## Rule

Do not trust a model only because it runs. Always evaluate it.
